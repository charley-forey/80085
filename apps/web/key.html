🔑 Getting a key

Self-serve signup is not built yet. Keys are issued by hand while the API is in MVP, because the endpoint that mints them also grants every scope, and putting that behind a public form would be a security bug wearing a signup button.

Open an issue on GitHub and ask. That is genuinely the whole process today.

When self-serve exists, this page becomes the form and the status block on the homepage loses a 🚧.
